### 3.2 P0问题详解：单文件入队缺少advance()调用

**代码对比**:

```python
# 批量入队（正确）- src/services/ingest.py:258-260
svc = get_default_queue_service()
for _ in range(6):
    svc.advance(project_id=resolved_id)  # ✓ 触发消费

# 单文件入队（错误）- src/services/ingest.py:186-190
task_id = enqueue_task(...)
if not task_id:
    return {"status": "ignored", ...}
return {"status": "queued", ...}  # ✗ 缺少advance()调用！
```

**影响**: 通过API提交单个文件后，任务入队但不会被自动处理，需要手动调用 `/queue/resume` 或等待服务重启。

**修复建议**: 在单文件入队返回前添加 `svc.advance()` 调用。

### 3.3 P1问题详解：页面内容槽位未填充

**现象**: 所有生成的wiki页面的body槽位都是"（待补充）"

```markdown
## 来源元数据

（待补充）

## 摘要

（待补充）

## 关键观点

（待补充）
```

**可能原因**:
1. Generator设计为只生成frontmatter
2. Body填充逻辑未执行或超时
3. 需要后续polish流程补充

**需要确认**: 检查Generator是否应该生成body内容。
