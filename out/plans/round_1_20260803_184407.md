## 发现的问题

### P0 - 队列消费机制缺失（严重）

**现象**:
- 任务成功入队（status: pending）
- 但队列消费完全停滞，任务从未被处理
- pending_count 持续为 3，running_count 始终为 0

**根因分析**:
1. **队列暂停状态遗留**: `.kb-queue-paused` 文件存在，导致队列处于 `paused: true` 状态
2. **事件处理器未注册**: 当前进程的事件总线 `_handlers` 为空，`collector:start` 事件无监听器
3. **进程隔离问题**: 服务进程与CLI进程独立运行，事件处理器只在服务进程内注册
4. **缺少自动恢复机制**: 新任务入队后没有触发 `advance()` 的机制

**证据**:
```
队列状态: {'paused': true, 'pending_count': 3, 'running_count': 0}
事件处理器: Registered handlers: (空)
```

## 优化方案

### 方案 A: 自动恢复队列消费（推荐）

**目标**: 确保任务入队后能被自动消费

**实施步骤**:

1. **入队时自动触发调度**
   ```python
   # src/queue/service.py - enqueue() 方法
   def enqueue(self, ...):
       # ... 入队逻辑 ...

       # 如果队列未满，尝试调度一个任务
       if self.get_status()["running_count"] < MAX_CONCURRENT:
           self._schedule_advance_async()
   ```

2. **添加队列状态检查API**
   ```
   GET /api/v1/queue/status → {paused, pending_count, running_count}
   POST /api/v1/queue/resume → 恢复队列
   ```

3. **服务启动时清理孤儿暂停文件**
   ```python
   # src/server/app.py lifespan
   if Path(".kb-queue-paused").exists():
       # 检查是否有正在运行的服务实例
       if not other_instance_running():
           Path(".kb-queue-paused").unlink()
           logger.info("[startup] cleaned up orphan pause file")
   ```

### 方案 B: 事件驱动消费模式

**目标**: 完全消除 `advance()` 调用依赖

**实施步骤**:

1. **任务入队直接发送 collector:start 事件**
   ```python
   # src/services/ingest.py
   event_bus.emit("collector:start", CollectorStartPayload(
       task_id=task.id,
       source=task.source,
       project_id=task.project_id,
   ))
   ```

2. **添加任务完成后的链式调度**
   ```python
   # src/pipeline/service.py
   @event_bus.on("task:completed")
   async def on_task_completed(payload):
       # 尝试调度下一个任务
       svc = get_default_queue_service()
       svc.advance()
   ```

### 方案 C: 后台Worker进程

**目标**: 解耦服务进程与队列消费

**实施步骤**:

1. **添加独立Worker进程**
   ```bash
   python -m src.cli queue-worker [--concurrency 6]
   ```

2. **使用信号量控制并发**
   ```python
   class QueueWorker:
       def __init__(self, max_concurrent: int = 6):
           self.semaphore = asyncio.Semaphore(max_concurrent)

       async def run(self):
           while True:
               async with self.semaphore:
                   task = select_next_task()
                   if task:
                       await process_task(task)
               await asyncio.sleep(1)
   ```
