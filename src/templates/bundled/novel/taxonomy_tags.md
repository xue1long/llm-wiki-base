# Taxonomy — Tags 枚举节（独立文件）

> 与 `taxonomy.md` 的分类轴（`## 分类`）**独立解析**，避免污染分类命名空间（O5）。
> 本文件是 tags 受控枚举的单一真源（spec §4.4）。前缀 `prefix/` 后跟值，格式 `prefix/value`。
> 保留前缀的语义沿用平台现状；`情绪/` `场景阶段/` 收紧枚举与存量旧值做并集过渡（Phase 4 后清理旧值）。

| 前缀 | 状态 | 受控枚举 |
|---|---|---|
| `情绪/` | 收紧 | 爽、虐、甜、燃、悬疑、惊悚、治愈、热血、轻松、沉重 |
| `场景阶段/` | 收紧 | 开篇、发展、高潮、结局、日常、战斗、情感、悬疑 |
| `读者群/` | **新增** | 男频、女频、全年龄、青少年、中老年 |
| `平台/` | **新增** | 起点、番茄、晋江、纵横、飞卢、QQ阅读、掌阅 |
| `题材/` | 保留 | 现有语义不变（题材类型） |
| `功能/` | 保留 | 现有语义不变（功能类型） |
| `角色/` | 保留 | 现有语义不变（角色类型） |
| `事件/` | 保留 | 现有语义不变（事件类型） |
| `实体/` | 保留 | 现有语义不变（实体类型） |
| `状态/` | 保留 | 现有语义不变（生命周期） |
| `素材/` | 保留 | 现有语义不变（如 `素材/ugc`） |
| `可信度/` | 保留 | 现有语义不变（如 `可信度/ugc`） |

> **并集过渡（H4）**：`情绪/` `场景阶段/` 收紧枚举 ∪ 存量旧值（甜宠、虐文、爽文、正剧、暗黑 / 转折、铺垫、过渡、冲突、收束），门禁对存量页豁免，Phase 4 后清理旧值。
