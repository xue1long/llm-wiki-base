# Wiki Schema

## Page Types

| type | directory |
|------|-----------|
| source | wiki/sources |
| entity | wiki/entities |
| concept | wiki/concepts |
| synthesis | wiki/synthesis |

## Conventions

- 页面使用 YAML frontmatter 和 `[[wikilink]]` 交叉引用。
- 快速捕获页面通过 body 注释 `<!-- capture-type: article -->` 标记子类型。
