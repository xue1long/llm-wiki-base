# 书系目标方案整改记录

**依据：** `docs/reports/2026-09-06-book-series-target-audit-v2.md`
**整改对象：** 三本主教程 + 参考库目标方案
**当前状态：** 已完成文档级整改，尚未完成数据门和代码实现。

## 已整改的审计问题

| 审计问题 | 方案整改 |
|---|---|
| 三本书未经数据证明 | 增加 Task 0 前置数据门；允许合并、降级或取消候选书 |
| 缺少书系数据模型 | 增加 `series-manifest-v1`、book manifest、状态机、批次一致性和旧版兼容规则 |
| 参考库可选但被主教程依赖 | 增加 hard/soft 依赖；hard 缺失阻断，soft 缺失要求正文自足 |
| 页面多重归属无裁决 | 增加 primary book/chapter、secondary topics、裁决理由和人工裁决记录 |
| 跨书关系可能成环或漂移 | 增加无环依赖图、悬空目标检查和 release/outline 版本绑定 |
| 聚合来源覆盖掩盖关键缺失 | 增加章节级 80% 下限和关键事实 100% 证据门 |
| 10 章和 8–15 章过度预设 | 改为按学习链、出口产物和页面密度决定；不足时缩短并记录 |
| LLM 敏感扫描不可执行 | 将扫描、脱敏、拒绝、人工豁免和审计事件列为 Provider 前置任务 |
| 书系部分成功状态不清 | 增加 `draft/partial/ready/invalid` 状态和同批次发布规则 |
| 练习成果无法跨章传递 | 将 `exit_artifact` 和 reader task 作为前置数据门和章节硬契约 |
| 增量变更会污染旧关系 | 关系索引绑定 release/outline，后续任务要求 fingerprint 增量失效 |
| WebUI 无法表达未就绪状态 | 增加 `partial/invalid/dependency_missing` 展示要求 |
