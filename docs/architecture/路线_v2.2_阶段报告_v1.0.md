### 7.1 `scripts` 命名空间污染

> **现象**：兄弟 repo `D:\5-Project\2026814\llm-wiki-base` 通过 `pip install -e .` 注册了 `src/scripts/` 包，导致 `scripts/kc_*.py` 命名冲突。

> **影响范围**：本路线所有新增 test 文件。

### 7.2 `_ko_extra` 多业务共用

> 4 commit 演进（source_status / memory.decision / provenance 保留 / evidence）：
> 4 类 → 1 类（仅 provenance 保留，因 spec §5.7 Evidence 内部字段保护）。
