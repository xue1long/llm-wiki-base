## 4. 关键设计发现汇总

1. **`scripts` 命名空间污染**：兄弟 repo `D:\5-Project\2026814\llm-wiki-base` 通过 `pip install -e .` 注册 `src/scripts/` → 所有测试用 `importlib` 动态加载
2. **`_ko_extra` 多业务共用** → 4 commit 演进（4 类 → 1 类保留）
3. **`KnowledgeObject` 实际 12 字段**（非 stub 假定的 2 字段）→ 不能用 subclass，直接追加 back-compat 默认字段
4. **`hasattr`-probe 模式**：Gate 对未固化字段自动跳过（ProvenanceGate 4 维度）
5. **A-1 dry-run 实测**：novel-wiki 叙述类仅 66 页（1.3%）→ F-3 风险比预估小 60 倍
6. **subagent 持续失败**（identity_key 3 次 + B-4 1 次 + B-5 3 次）：主 agent 直接实现更可靠
7. **A-0 delivery_report 守门**实际工作：B-2.3 漏 `migration_required` 字段被捕获
